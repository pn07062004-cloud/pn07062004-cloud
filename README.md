## 🚀 Featured Project

### 📚 Smart Library Microservices

A full-stack **Smart Library Management System** designed with a **Microservices Architecture**.

The project separates major business responsibilities into independent services and provides both backend APIs and a frontend interface for library users and administrators.

### 🧩 Main Components

* 🔐 **Authentication Service** — User authentication and account management
* 📚 **Catalog Service** — Book and catalog management
* 🔄 **Circulation Service** — Borrowing, returning and reservations
* 💳 **Payment Service** — Fine and payment processing
* 🤖 **Chatbot Service** — Intelligent library support
* 🌐 **API Gateway** — Central entry point for backend services
* 🔎 **Discovery Server** — Service discovery
* ⚛️ **React Frontend** — User and administrator interfaces
* 🐳 **Docker** — Containerized development environment
